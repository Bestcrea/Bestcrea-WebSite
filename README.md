# Bestcrea

Next.js 14 (App Router) + TypeScript project for Bestcrea.

## Stack

- Tailwind CSS + shadcn/ui
- next-intl (`fr` / `en` / `ar` / `es` / `de`, default `fr`, RTL for `ar`)
- Prisma + PostgreSQL
- NextAuth.js
- Framer Motion

## Getting started

```bash
cp .env.example .env
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) — you will be redirected to `/fr`.
